<Section title="The challenge">
Bhutan lacks an open and reliable cab-booking system. People still depend on manual calls or
emails to find a ride, with limited providers, low vehicle availability, and very few car types.
This makes booking slow, uncertain, and inconvenient for both tourists and local users.
</Section>

<Section title="The approach">
I designed a complete cab-booking platform that brings all travel needs into one simple,
trustworthy system. The solution includes clear booking flows, transparent pricing, verified
drivers, multiple vehicle options, and a mobile-first interface. Users can easily book local
rides, outstation trips, rentals, and custom routes with confidence and convenience.
</Section>

<Section title="The outcome">
A complete, mobile-responsive design covering the full booking journey — search and filtering,
vehicle comparison, account creation, OTP verification, payment and confirmation — delivered as a
consistent UI system rather than a set of isolated screens.

- Mapped the existing manual booking journey (phone calls, messaging apps) to find where trust and
  clarity broke down.
- Defined a booking flow that surfaces price, vehicle type, and driver details up front.
- Designed for both tourist and local use cases within the same core flow, rather than splitting
  into separate products.
</Section>
